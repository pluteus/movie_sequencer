⚙ 設定
連続再生中に、同じノード／矢印へ入ろうとして回数がこの値に達すると、ランダムなノードまたは矢印へジャンプして再生を再開します。
矢印の説明文（動画プロンプト）で、セリフや効果音のほかに書いてよい、言葉でない声・口の音です。このリストにあるものだけが使われます。画像は上のURLのサーバーにだけ送られます。
長押しメニューの「✨ Geminiでタグ付け」「✨ Geminiで説明文を追加」と、🛠 編集メニューの「✨ 画像にタグ付け（Gemini）」で使います。タグの語彙・説明文の項目などの設定は、LM Studio と共通です。画像（キャラクター部分を切り出して縮小したもの）は Google の Gemini API に送信され、API キーはこの端末のブラウザにだけ保存されます。
語彙を入れると、その中からだけタグを選びます（表記ゆれを防げます）。ネガティブリストのタグは使わせず、返ってきても除外します（全画像に共通するタグなどを外せます）。語彙は、説明文の生成でも、優先する語・使わない語として使われます。
長押しメニューの「✂️ 背景を除去」で使います。画像はこの端末の中だけで処理されます（初回のみモデルをダウンロードします）。「透明」以外は、背景をその色で塗ったPNGになります。
